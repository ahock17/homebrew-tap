# ahock17/tap

Personal Homebrew tap.

```sh
brew install --cask ahock17/tap/plezy
```

| Cask | Upstream | Updates |
|---|---|---|
| `plezy` | [edde746/plezy](https://github.com/edde746/plezy) | `.github/workflows/bump.yml` checks for a new release every 6 hours and commits the new `version`/`sha256`; `brew update && brew upgrade` installs it. |
